CroC UI by tuxlab

Interfaccia grafica per croc — trasferimento file sicuro peer-to-peer

📤 Inviare file

  1. Trascina i file o clicca sull'area per selezionarli
  2. Scegli una passphrase personalizzata o usa quella generata automaticamente
  3. Clicca Send Files per avviare il trasferimento
  4. Condividi il codice mostrato con il destinatario

📥 Ricevere file

  1. Vai alla scheda Receive
  2. Inserisci il codice fornito dal mittente
  3. Cambia la cartella di destinazione se necessario
  4. Clicca Receive per iniziare il download

🔐 Sicurezza

Tutti i trasferimenti sono crittografati end-to-end con TLS. I file non passano mai da server — i dati fluiscono direttamente tra i peer tramite NAT traversal. La passphrase è il vostro segreto condiviso.

🔧 Requisiti

croc CLI deve essere installato sia sul mittente che sul destinatario. Croc UI by tuxlab utilizza il binario di croc — non serve connessione internet dopo la configurazione iniziale.
